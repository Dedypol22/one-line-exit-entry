A one-line resignation letter: "Please accept my resignation: the office Wi-Fi has been down for six weeks, and as of today, so have I." One word — "down" — does double duty, first as a dead network, then as a person who has finally stopped functioning.

## Run it

```sh
python3 main.py
```

It writes the line to /output/entry.txt (or MAKEFUN_OUTPUT_DIR) with no trailing newline.
